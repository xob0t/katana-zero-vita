03Playon the Vita

    

      
    
        
  1. The Vita needs HENkaku or Ensō, VitaShell, and three plugins:
          kubridge,
          FdFix and
          libshacccg.suprx
          (how to get it).
    2. 
        
  2. Copy KatanaZero.vpk to ux0:VPK/ over USB or FTP. Leave about 550 MB free on the
          memory card for the install.
    3. 
        
  3. In VitaShell, press ✕ on the VPK to install it. Delete the
          VPK afterwards.
    4. 
        
  4. The first launch compiles every shader and takes about 3 minutes. After that it's about a minute.
    5. 
      

      
Settings live in ux0:data/gms/katanazero/yyl.cfg; the
        README lists them. To update, build a new
        VPK and install it over the old one. Your saves stay.
