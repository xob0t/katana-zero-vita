Katana ZERO for PS Vita

VPK builder

A fan port of Katana ZERO to the PS Vita. The game is not included. You need your own copy: the Netflix Android release, version 1.1.10.

Local Your APK never leaves this computer. The VPK is built in your browser. Use a desktop browser: the build takes about a minute and holds the 250 MB VPK in memory.

3 Install it on your Vita

    
    
      
  1. Your Vita needs HENkaku or Ensō, VitaShell, and these plugins:
        kubridge,
        FdFix and
        libshacccg.suprx
        (how to get it).
    2. 
      
  2. Copy KatanaZero.vpk to ux0:VPK/ over USB or FTP. The
        memory card needs about 550 MB free while installing.
    3. 
      
  3. In VitaShell, press cross on the VPK and confirm. Delete the VPK afterwards.
    4. 
      
  4. The first launch compiles every shader, which takes about 3 minutes. Later launches take about a minute.
    5. 
    

    
Settings are in ux0:data/gms/katanazero/yyl.cfg. The
      README lists them. To update the port, build a
      new VPK here and install it over the old one. Your saves stay.
